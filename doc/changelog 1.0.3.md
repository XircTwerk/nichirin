# New Features

## Configuration Menu
- Added in-game configuration settings via Cloth Config  
- Toggle visual effects on/off:
  - Breathing aura particles
  - Hit particles
  - Parry sparks

## New Particle Effects
- **Breathing Aura Wisps**
  - Colored particles that surround players using breathing styles  
  - Each breathing style has its own unique color  
  - Gentle floating animation  

- **Blood Splat Particles**
  - Impact effects when landing hits  

- **Slash Impact Sparks**
  - Visual feedback from attacks  

## New Armor Sets
- **Shinobu's Outfit**
  - Includes cape with arm wraps  

- **Zenitsu's Outfit**
  - Complete uniform with flowing cape  

- **Rengoku's Outfit**
  - Fiery haori cape and uniform  

- **Tengen's Outfit**
  - Decorative accessories and uniform  

- **Sabito's Outfit**
  - Demon slayer uniform with cape  

- **Giyu's Outfit**
  - Water Hashira inspired uniform with cape  

- **Urokodaki's Outfit**
  - Mountain trainer gear with cape  

- Armor pieces now animate properly with player movement and breathing styles  

## Combat Improvements
- Players can now use basic katana moves without selecting a breathing style:
  - Check stance
  - Overhead strike
  - Thrust attack  

- Attack wheel now shows the correct moves based on what you're holding  

## New Breathing Style
- Water Breathing now available to unlock  

## Visual Polish
- Blood moon creates a red atmospheric tint at night  
- Better animation transitions for all combat moves  
- Aura particles change color based on your breathing style  

## Bug Fixes
- Fixed blocking and click detection issues in menus  
- Fixed tooltips going off-screen in GUIs  
- Improved animation system reliability  
- Better armor rendering when wearing different pieces  
- Fixed cooldown display for attacks
